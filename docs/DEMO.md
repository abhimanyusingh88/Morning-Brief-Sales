# Two-minute demo

Start: `DEV_DB=pglite npm run dev` (or against Supabase), sign in with the persona picker.

1. **Admin (Sam Whitaker) → Morning run.** Leave *Time-lapse* on and press **Run the morning**. In about 90 seconds the simulated clock runs 04:00 → 06:30 ET: 14 feeds connect, content is tagged and matched to each salesperson's book, facts are built, the Catalysts section is written, every figure is validated, QC runs, briefs publish and email digests are rendered.
2. Optional before pressing run: add a **feed problem** (e.g. pre-market snapshot *Down*) to show dependent sections withheld with "Data temporarily unavailable.", or switch on **Spot-check holds one brief**.
3. **Data feeds** — open any connector: endpoint, SLA, payload sample, and what the firm provides to take it live.
4. **QC review** — the 8 checks per brief; hold or release one. **Deliveries** — preview an email digest (preview only).
5. **Sign out → Aisha Rahman.** *Morning brief* (the spec-style page, hover figures for source and time), *Today*, *Agent* (ask "Who should I call first this morning, and why?", then the draft follow-up), *Brief setup* (changes apply from the next business day).

Warm the model cache once before a live showing if a model key is configured; reruns are then instant.
